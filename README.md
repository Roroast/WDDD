# WDDD

This repository provides software and data to implement the simulated and real data calculations in [Talbut et al.](https://arxiv.org/abs/2307.02846). We computed a generalised Wasserstein distance between phylogenetic tree datasets with different leaf sets using the tropical metric.

The Wasserstein distance is a metric between probability distributions or point sets defined via optimal transport theory. The generalised Wasserstein distances computed in our repository use a tropical metric as a ground metric to compare phylogenetic datasets that may have different sets of taxa (leaf nodes), which is a common challenge in phylogenetic statisics. By leveraging the tropical metric on tree spaces, we can compute these distances efficiently.

For more detail on the underlying theory of Wasserstein distances between tropical spaces of different dimensions, please see [Talbut et al.](https://arxiv.org/abs/2307.02846).

## Data Availability and Preprocessing
The real phylogenetic data in this repository (`Data/N_NYh3n2_HA_20000_5`) is computed from the genetic sequences of the influenza A H3N2 hemagglutinin obtained
for New York, 1993-2017, from the [GI-SAID EpiFlu&trade;](https://www.gisaid.org/) database. The raw
genomic data was then aligned using [MUSCLE](https://www.ebi.ac.uk/Tools/msa/muscle/) with default settings, to construct a single
large phylogenetic tree for the influenza strains across all seasons. Finally, 
[tree dimensionality reduction](https://arxiv.org/abs/1607.07503) is applied to represent this large phylogenetic tree as a dataset of smaller trees using
temporal windows of 5 years; this produces 21 datasets of approximately 20,000 trees each, where the leaf
set of a given dataset corresponds to 5 consecutive years. For further details on data pre-processing, see
[Monod et al.](https://arxiv.org/abs/1805.12400).

## Description of Python Scripts

The repository contains the following set of Python scripts:

* `WDDD_class.py` defines the core WDDD class for computing Wasserstein distances between tree datasets.
* `trop_fns.py` provides supplemental tropical geometry functions used in distance computation.
* `experiments.py` contains functions to run numerical experiements on Wasserstein distance computations.
* `real_data_computation.py` applies the WDDD methodology to real phylogenetic datasets.
* `sim_data_computation.py` applies the WDDD methodology to simulated phylogenetic datasets.
* `shift_descent_training.py` optimizes shift parameters for improved distance estimates.
* `shift_optimisation_training.py` optimizes shift parameters over different matrix supports. 
* `supp_descent_training.py` implements supplementary simulated annealing optimization for distance computation.

The Jupyter notebook `WDDD_notebook.ipynb` presents a step-by-step exploration of the results shown in [Talbut et al.](https://arxiv.org/abs/2307.02846).

## Output and Results

The `DataFrames` directory contains computed results generated by the analysis scripts. The `Figures` directory contains visualizations and plots of the Wasserstein distance computations and comparative analyses across different tree datasets.
